# Hackathon demo — Radiology Agent

**Not for medical use, research only.**

The Mac app and Codex connector share the same Horos worklist, original-DICOM Cornerstone3D viewer, report document, and key-image links. Codex remains the agent; the Mac app is its radiology companion workspace.

## Before presenting

- Open Horos and Radiology Agent. Keep Codex available beside the app if showing the agent conversation.
- Open the completed two-view x-ray, then the CT series you intend to show. Allow selected-series caching to finish before recording a scrolling demonstration.
- Use the existing display aliases if appropriate for the event. They change on-screen labels only; they do not de-identify the original DICOM pixels or files.
- Check the evaluation draft and its key-image links. Keep the report unsigned.

## A two-minute walkthrough

1. **Worklist:** show that the app sees the studies already in Horos. Incoming studies enter the connector’s existing listener and Codex workflow.
2. **Read together:** open the completed x-ray. Images and the shared evaluation report appear side by side.
3. **Inspect evidence:** hover a linked report phrase to preview its key image. Click the phrase to keep that image selected, then inspect it with window/level, pan, or zoom.
4. **Navigate a stack:** open the CT and scroll a cached series. Explain that the viewport receives original DICOM data and displays locally; radiologist gestures are synchronized afterward.
5. **Keep control:** manual navigation pauses following. Resume following Codex when you want to watch the agent again.
6. **Drafting:** show Edit draft and Cancel, or make a real authorized edit and save it. Report revisions protect concurrent changes. The Word-report workflow remains available through the connector.

Clicking a series thumbnail stays inside the app. The explicit **Open in Horos** button, or the user-requested double-click on the displayed image, opens the selected native series/frame.

The original PNG logo is supplied by the project owner. The app icon and interface reuse that artwork, cropped and resized only for asset packaging.
